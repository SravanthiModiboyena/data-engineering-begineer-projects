# Project 4: Spark Log Processing

## Objective
Analyze web server logs using Apache Spark (PySpark).

## Tech Stack
- Apache Spark 3.5
- PySpark
- Python
- Linux (WSL)

## Features
- Extract IP addresses
- Extract HTTP status codes
- Count status occurrences
- Identify top IP addresses
- Save processed output

## Project Structure
4_spark_log_processing/
 ├── data/
 ├── scripts/
 ├── output/

## Run Command
spark-submit scripts/log_analysis.py
