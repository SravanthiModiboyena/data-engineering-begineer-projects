# Project 4: Spark Log Processing

## Overview
This project demonstrates log data processing using Apache Spark.

## Tools Used
- Apache Spark 3.5.0
- Python
- Linux (WSL)

## Features
- Extract IP addresses
- Extract HTTP methods
- Extract endpoints
- Count status codes
- Identify top IP addresses

## Output Example
- Status 200 count
- Status 404 count
- Status 500 count
- Top IP traffic
